# utask-feed

优学院作业助手（UTaskDesktop）的 **在线更新物料仓库**。

这个仓库只放分发物料，**不含任何源码**。源码在私有仓库里。

---

## 客户端怎么用

客户端启动后（以及用户点「检查更新」时）读这个文件：

```
https://raw.githubusercontent.com/zqs74/utask-feed/feed/manifest.json
```

里面写着：

- `latest` —— 当前最新版本号、更新要点、完整安装包入口
- `patches` —— 一份「从某个旧版本一步升到最新版」的增量包列表
- `versionNotes` —— 每个历史版本的更新要点

客户端拿自己的版本号去 `patches` 里找 `from` 完全相同的那一条，下载对应的包，逐个文件校验 SHA256 之后替换。找不到就直接引导去 [Releases](../../releases) 下完整安装包。

---

## 目录结构

```
manifest.json          客户端读的唯一入口
manifests/<版本>.json   每个已发布版本的全量文件清单（含每个文件的 SHA256）
patches/<旧>-to-<新>-<内容指纹>.zip   增量包
```

增量包文件名末尾那 8 位是内容指纹。同名文件会被 CDN 缓存，内容变了名字没变的话，客户端拿到的还是旧包，校验必然失败——所以名字里必须带指纹。

---

## 安装包

完整安装包在 [Releases](../../releases) 页面，不放在分支里。

首次安装、或者从很老的版本跨太多版本升级时，用那里的 exe。

---

## 注意

- **不要手动改这里的文件**。每次发版由代码仓库里的 `tools\publish-update.ps1` 自动生成并推送，手改会在下一次发版时被覆盖。
- 单个包请控制在 **10 MB** 以内。超过的话发布脚本会自动切成 `.part001`、`.part002` 分片，客户端逐片下载再拼回整包——这是为了绕开部分托管站对匿名下载大文件的限制。
- 分支固定是 `feed`，默认分支也是它，方便裸 URL 访问。
